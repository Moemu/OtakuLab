## VSS 口径

维护者已确认，论文中的实验数据按以下公式计算：

```text
VSS = style_score × (1 if semantic_score > 0.75 else 0.1)
```

主评估、显著性检验和论文图表采用此口径。33、38 号 Notebook 已使用 0.1。已提交和本地保存的主 VSS 数组也已核对通过，无需重算。

乘 0 的辅助脚本和 `evaluate_result_vss_hard.jsonl` 属于对照分析，不替代主实验结果。
